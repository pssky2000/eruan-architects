# 디자인 메모

사이트를 고칠 때 이 기준을 지킨다.

## 생각
첫 화면은 건물 도면 한 장이다. 입면 드로잉이 한 번 그려지고, 옆의 표제란(도면 정보 칸)에 사무소의 실제 정보만 적는다.
분위기는 PRD의 "깔끔한" + 참고 자료의 어두운 바탕·청동색 선·세리프 제목. 참고 자료의 신경망 선, 가격표, 팀 소개, 유리 카드는 가져오지 않았다.

## 색
- 먹(바탕) `#15130F`
- 면(칸 바탕) `#1D1A15`
- 선 `#3A342B`
- 한지(글자) `#ECE5D8`
- 회색(보조 글자) `#A39B8E`
- 청동(강조) `#B59876`, 밝은 청동 `#D6BE9C`

## 글꼴
- 제목: Hahmlet (가는 굵기 300~400)
- 본문·버튼: Pretendard

## 지킬 것
- 움직임은 첫 화면 드로잉 하나만. 동작 줄이기 설정이면 바로 다 그려진 상태로.
- 영문 대문자 라벨, 01/02 번호, 버튼 끝 화살표는 쓰지 않는다.
- 작품·후기·숫자는 실제 것만. 없으면 비워 두고 솔직하게 적는다.
- 작품 사진은 흑백으로 보이다가 손을 올리면 색이 돌아온다.
