# 사이트 설계도(PRD) — 이루안 건축사사무소

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
주거·상업·업무·공공까지 모든 건축물을 설계하는 건축사사무소를 소개하고, 작품을 보여 주고, 설계 상담 신청을 받는 사이트.

## 2. 손님
- 누가: 건물을 지으려는 사업자 (상가·사옥·임대 건물 등)
- 어디서 알고 오나: 인터넷 검색, AI 검색

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 설계비·기간
2. (미정)
3. (미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 완공 작품 사진
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 설계 상담 신청
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + 버튼(설계 상담 신청)
2. 대표 작품 — 완공 작품 사진 몇 점 + "작품 더 보기"(작품 페이지로)
3. 사무소 소개 — 하는 일(모든 건축물 설계)과 설계비·기간 안내("규모별로 상담 후 안내")
4. 후기 자리 (비워 둠)
5. 문의 폼 (설계 상담 신청)

페이지는 두 장: 첫 페이지(위 구성) + 작품 페이지(완공 작품 사진 모음). 관리자 화면 /admin은 따로.

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 건물 종류·규모 (예: 근린생활시설 4층, 대지 300㎡)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 사무소 이름: 이루안 건축사사무소
- 설계비: 규모별로 상담 후 안내
- 기간: 규모별로 상담 후 안내
- 위치: 충북 청주시 청원구 율량로 13
- 연락 방법: 043-224-7575

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 결제
- 관리자 화면에서 작품 사진 올리기 (이번엔 사진을 파일로 넣는다)
- 알림 메일
- 블로그·소식

## 10. 첫 화면 한 문장 후보
1. 짓고 싶은 건물이 있다면, 설계부터 함께 시작합니다.
2. 상가부터 사옥까지, 사업이 되는 건물을 설계합니다.
3. 대지와 계획을 알려 주시면, 설계 방향을 같이 잡아 드립니다.

## 11. 다음에 할 것
- 작품마다 건물 종류·규모·위치·완공 연도 정리하기
- 경력·자격 소개 넣기 (실제 내용이 정리되면)
- 인터넷·AI 검색에 잘 나오도록 사무소 정보(지역·분야)를 글로 분명히 적기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. (문의 저장이 '예'이므로) 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
